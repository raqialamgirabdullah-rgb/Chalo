# চলো — রিকশা-জাতীয় যানবাহনের রাইড-শেয়ারিং অ্যাপ (প্রথম সংস্করণ)

যাত্রী ফোনে গাড়ি ডাকে, কাছের চালক নেয়, দুজন লাইভ অবস্থান দেখে, শেষে নগদে ভাড়া মেটে।

- প্যাকেজ: `com.rahcare.rickshawride`
- Kotlin + Jetpack Compose, minSdk 26, targetSdk 34
- মানচিত্র: OpenStreetMap (osmdroid)
- ব্যাকএন্ড: Firebase (Firestore + Anonymous Auth), ফ্রি স্তর
- ভাড়ার হার বদলাতে: `app/src/main/java/com/rahcare/rickshawride/Models.kt` ফাইলের `FareConfig`

## ফাইল কোথায় কী

| ফাইল | কাজ |
|---|---|
| `Models.kt` | গাড়ির ধরন, ভাড়ার হার (`FareConfig`), রাইডের তথ্যের গঠন |
| `Geo.kt` | দূরত্ব (haversine × ১.৩)। `DistanceCalculator` ইন্টারফেস, পরে OSRM বসানোর জন্য |
| `Repo.kt` | Firestore-এর সব কাজ (রাইড ডাকা, transaction দিয়ে গ্রহণ, ধাপ বদল) |
| `LocationService.kt` | চালকের ফোরগ্রাউন্ড সার্ভিস, লাইভ অবস্থান পাঠায় |
| `AppViewModel.kt` | অ্যাপের যুক্তি |
| `Screens.kt`, `Ui.kt`, `OsmMap.kt` | সব পর্দা (বাংলা), মানচিত্র |
| `firestore.rules` | Firestore নিরাপত্তা নিয়ম |
| `.github/workflows/build.yml` | স্বয়ংক্রিয় APK বিল্ড ও Releases-এ প্রকাশ |

## আপনার করণীয় (ফোন থেকে)

### ক) Firebase প্রজেক্ট
1. `console.firebase.google.com` → Google অ্যাকাউন্টে ঢুকুন → **Create a project** → নাম `rahcare-rickshawride` → Google Analytics বন্ধ → Create।
2. **Build → Authentication → Get started → Sign-in method → Anonymous → Enable → Save**।
3. **Build → Firestore Database → Create database → Production mode** → লোকেশন `asia-south1` → Enable।
4. প্রজেক্টের হোমে **Android আইকন** → প্যাকেজ নাম হুবহু `com.rahcare.rickshawride` → Register app → **`google-services.json` ডাউনলোড**। বাকি ধাপ বাদ দিন।
5. ফাইলটির সব লেখা কপি করে Claude-কে পাঠান। Claude সেটি `app/google-services.json` হিসেবে রাখবে। এটি না থাকলে বিল্ড চলে না।

### খ) Security Rules
- Firestore Database → **Rules** ট্যাব → সব লেখা মুছে এই রিপোজিটরির `firestore.rules` ফাইলের পুরো লেখা পেস্ট → **Publish**।

### গ) সাইন করার চাবি (একবারের কাজ)
GitHub-এ রিপোজিটরি `Chalo` → **Settings → Secrets and variables → Actions → New repository secret**। চারটি secret বানান (নাম হুবহু বড় হাতের):
`KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`।
মানগুলো Claude আপনাকে আলাদা ফাইলে দিয়েছে। **ঐ চাবির ফাইলের ব্যাকআপ নিরাপদ জায়গায় রাখুন।** হারালে পুরোনো অ্যাপের ওপর নতুন সংস্করণ ইনস্টল হবে না।

### ঘ) APK নামানো
- রিপোজিটরি → **Releases** → সর্বশেষ সংস্করণ → `RickshawRide.apk` চাপুন। ফোনে "অজানা উৎস থেকে ইনস্টল" অনুমতি দিতে হতে পারে।
- বিল্ড ফেল করলে `build-logs` ব্রাঞ্চের `build-error.txt` ফাইলটি Claude-কে দেখান।

## দুটি ফোনে পরীক্ষার তালিকা (ফোন ক = যাত্রী, ফোন খ = চালক)

1. দুই ফোনে APK ইনস্টল করে খুলুন। ফোন ক-তে "আমি যাত্রী", ফোন খ-তে "আমি চালক" বেছে নাম/ফোন দিন। চালক গাড়ির ধরন বাছুন (যেমন রিকশা)।
2. ফোন খ: লোকেশন ও নোটিফিকেশন অনুমতি দিন, সুইচ চালু করে **অনলাইন** হোন। উপরে নোটিফিকেশন দেখা যাচ্ছে কি না দেখুন।
3. ফোন ক: লোকেশন অনুমতি দিন। সবুজ পিন নিজের জায়গায় আছে কি না দেখুন। মানচিত্র সরিয়ে পিন নড়ে কি না দেখুন। "পিকআপ ঠিক আছে" চাপুন।
4. ফোন ক: গন্তব্যে ট্যাপ করুন (পিন ওখানে চলে আসবে)। "গন্তব্য ঠিক আছে"। রিকশা বাছুন, ভাড়া ও দূরত্ব ঠিক দেখাচ্ছে কি না দেখুন। "রাইড ডাকুন"।
5. ফোন খ: ৩ কিমির মধ্যে রিকোয়েস্ট আসছে কি না দেখুন। (দুই ফোন কাছাকাছি রাখুন।) "গ্রহণ" চাপুন।
6. ফোন ক: চালকের নাম, ফোন, গাড়ি ও কমলা বিন্দু (চালকের লাইভ অবস্থান) দেখা যাচ্ছে কি না দেখুন। ফোন খ হাতে নিয়ে হাঁটলে কমলা বিন্দু নড়ে কি না দেখুন।
7. ফোন খ: "পৌঁছেছি" → "যাত্রা শুরু" → "যাত্রা শেষ"। ফোন ক-তে প্রতিটি ধাপ বদলায় কি না দেখুন। শেষে "ভাড়া: X টাকা, নগদে দিন" পর্দা আসবে।
8. দুই ফোনেই নিচের ডান ট্যাবে পুরোনো রাইডের তালিকা (চালকের ক্ষেত্রে আয়সহ) দেখুন।
9. বাতিল পরীক্ষা: ফোন ক রাইড ডেকে ফোন খ অফলাইন রাখুন। ৩ মিনিট পর নিজে বাতিল হয় কি না দেখুন। আরেকবার রাইড চলাকালীন "রাইড বাতিল করুন" চাপুন।
10. একই সময়ে দুজন চালকে (তৃতীয় ফোন বা দুই অ্যাকাউন্টে) "গ্রহণ" চাপলে শুধু একজন পাচ্ছে কি না দেখুন।

## প্রথম সংস্করণে যা নেই এবং পরে কীভাবে যোগ হবে

| নেই | পরে কীভাবে |
|---|---|
| SMS OTP লগইন | Firebase Phone Auth যোগ হবে। এর জন্য Blaze (কার্ড লাগে) প্ল্যান লাগতে পারে, ও SHA-1/SHA-256 কনসোলে দিতে হবে। |
| অনলাইন পেমেন্ট | bKash/Nagad মার্চেন্ট API, এর জন্য আলাদা মার্চেন্ট অ্যাকাউন্ট ও সার্ভার লাগে। |
| চালক যাচাই | চালকের নথি/ছবি Firebase Storage-এ তুলে অ্যাডমিন যাচাই করার পর `verified` চিহ্ন, রুলসে শুধু যাচাইকৃত চালক গ্রহণ করতে পারবে। |
| রেটিং | রাইড শেষে `rides/{id}`-এ রেটিং ফিল্ড ও `ratings` সংগ্রহ। |
| রাস্তা ধরে রুট ও দূরত্ব | `DistanceCalculator` ইন্টারফেসে OSRM-এর নতুন একটি ক্লাস লিখে `DistanceProvider.calculator`-এ বসালেই হবে। |
| সার্ভার-পক্ষের স্বয়ংক্রিয় বাতিল | Cloud Functions (Blaze প্ল্যান) দিয়ে। এখন বাতিলটি যাত্রীর ফোন থেকে হয়। |
